# HTTP e TCP

## HTTP (HyperText Transfer Protocol)
- Protocolo de transferência de hipertexto
- Define as regras de comunicação entre navegador e servidor

## Hipertexto
- Texto que contém links/referências
- Ao clicar, leva para outro conteúdo

## TCP (Transmission Control Protocol)
- Protocolo de Controle de Transmissão
- Garante que os pacotes cheguem na ordem certa
- Evita que pacotes se percam ou se corrompam
- Funciona como um correio com confirmação de entrega

## UDP (User Datagram Protocol)
- Alternativa ao TCP, porém sem confirmação de entrega
- Mais rápido porém menos confiável
- Usado em videochamadas e jogos online
