# Terminal do Windows (CMD)

## Como acessar
- Buscar por **CMD** no Windows

## Conceito importante
- No Windows, **diretório** é o mesmo que **pasta**

## Comandos básicos
| Comando | O que faz |
|---|---|
| `dir` | Lista o conteúdo de um diretório |
| `cls` | Limpa o terminal |
| `hostname` | Mostra o nome da máquina |
| `ver` | Mostra a versão do Windows |
| `exit` | Fecha o terminal |
| `shutdown` | Desliga ou reinicia o computador |

## Navegação e criação de diretórios
| Comando | O que faz |
|---|---|
| `cd Documents` | Entra na pasta Documents |
| `mkdir teste` | Cria uma pasta chamada "teste" |

## Rede
| Comando | O que faz |
|---|---|
| `getmac` | Mostra o endereço físico (MAC) e nome de transporte |
| `ipconfig` | Mostra as configurações gerais da rede |
