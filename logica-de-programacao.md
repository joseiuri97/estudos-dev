# Lógica de Programação

## Algoritmos
São conjuntos de passos finitos e organizados que, quando executados, resolvem um determinado problema.

## Algoritmos Computacionais
São passos a serem seguidos por um módulo processador e seus respectivos usuários que, quando executados na ordem correta, conseguem realizar determinada tarefa. São rotinas.

- **Módulo processador** — tudo que pode efetuar processamento, tudo aquilo que pode ser programável
- **Usuários** — quem está utilizando

## Como é criado o algoritmo computacional
Lógica de Programação → Linguagem de Programação → Sistema Completo

## Variável
É um espaço no computador para guardar um valor. O valor pode mudar a qualquer momento, por isso se chama variável.

## Variável Simples
Guarda apenas um valor por vez. Quando um novo valor é colocado, o anterior é apagado.
