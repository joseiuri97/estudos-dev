# Lógica de Programação

## Algoritmos

São conjuntos de passos finitos e organizados que, quando executados, resolvem um determinado problema.

O importante é que os passos sejam:
- **Ordenados** → executados na sequência certa
- **Finitos** → têm um início e um fim
- **Claros** → sem ambiguidade, cada passo tem uma ação definida

Exemplos de algoritmos no dia a dia:
- Uma receita de bolo
- Um manual de instruções
- Um passo a passo para trocar um pneu

---

## Algoritmos Computacionais

São passos a serem seguidos por um módulo processador e seus respectivos usuários que, quando executados na ordem correta, conseguem realizar determinada tarefa. São rotinas.

- **Módulo processador** → tudo que pode efetuar processamento, tudo aquilo que pode ser programável
- **Usuários** → quem está utilizando

## Automação

Consiste em utilizar máquina(s) para executar um procedimento desejado de forma automática ou semiautomática — sem precisar de intervenção humana toda vez.

---

## Algoritmo, Automação e Programação

Três conceitos que andam juntos e formam a base da programação:

- **Algoritmo** → o raciocínio — a sequência de passos
- **Programação** → escrever o raciocínio numa linguagem que o computador entende
- **Automação** → o resultado — o computador executando sozinho

Se o algoritmo fosse uma receita de bolo, a programação seria escrever essa receita no idioma do computador, e a automação seria a máquina fazendo o bolo sozinha toda vez que você pedir.

---

## Exemplo real — app-notas

**Problema:** salvar notas sem perder quando fechar o navegador.

**Algoritmo criado:**
1. Usuário clica em salvar
2. Pega o título e o texto
3. Cria um objeto com os dados
4. Salva no localStorage
5. Atualiza a tela

**Resultado:** o JavaScript executa esses passos automaticamente toda vez que o usuário salva uma nota — sem intervenção manual.

---

## Por que lógica de programação vem antes de qualquer linguagem?

Porque a lógica é o raciocínio — e o raciocínio é o mesmo em qualquer linguagem. Quando você aprende a pensar algoritmicamente, você consegue programar em JavaScript, Python, Java ou qualquer outra linguagem. O que muda é apenas a sintaxe (a forma de escrever), não o raciocínio.

---

## Variável

É um espaço no computador para guardar um valor. O valor pode mudar a qualquer momento, por isso se chama variável.

---

## Variável Simples

Guarda apenas um valor por vez. Quando um novo valor é colocado, o anterior é apagado.
